# Cognixa UI — open correctly

## Wrong (causes `{{ c.n }}` / `{{ reviewVerdict… }}` errors)
- Double-click `Cognixa.html` **inside** the zip
- Open from `AppData\Local\Temp\…zip…`

## Right
1. Right-click zip → **Extract All…**
2. Open the extracted folder
3. Double-click **`START-COGNIXA.cmd`**
4. Browser opens `http://127.0.0.1:8765/Cognixa.html`

Needs Python on PATH (`py` or `python`).

## Files (keep together)
- Cognixa.html
- support.js
- vendor/react*.js
- FeedbackToast.dc.html
- START-COGNIXA.cmd
